# G7-A2-S6-R2-C-R1-A：一次性凭证形态布尔探针

## 目的

在不联网、不调用 Provider、不输出凭证或身份派生的前提下，只验证当前 Codex exec 登录 shell 中 `ANTHROPIC_API_KEY` 的四项形态：存在、单行、边界无空白、无成对包裹引号。

## 执行边界

- executor 默认 `check-only`，不读取环境变量。
- 仅显式 `--execute` 消费一次授权并读取环境变量一次。
- 值只在进程内用于布尔判断，随后释放引用。
- 只允许写一个 0600 回执；禁止记录或输出值、长度、前后缀、哈希、指纹及其他身份派生。
- 网络、Provider、远端、Docker、配置、服务、production/live Agent、commit 和 push 全部保持 0。

## 证据语义

四项通过只表示“当前启动环境中的非空字符串形态符合合同”，不证明它是新轮换值、DeepSeek 凭证、预期账户凭证或有效凭证。

用户本轮只授权执行探针，没有单独确认重新绑定和目标进程重启已经在探针前完成。因此回执固定记录 `rebindAndRestartConfirmedInThisTask=false`。如果形态通过，下一步先追加式确认该前置事实；如果前置事实未完成，则必须先重新绑定、重启，再另行授权新的形态探针。
